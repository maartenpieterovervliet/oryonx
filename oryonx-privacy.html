Deze website is een ontwikkelversie van ORYONX. Hieronder staat wat de huidige pagina’s doen.

Contact en je gespreksnotitie

Je kunt ORYONX bellen via +31 6 4229 6650. De velden op de contactpagina maken een notitie in je browser. Deze pagina verzendt de inhoud niet en schrijft die niet naar browseropslag. Kopiëren gebeurt alleen wanneer je daarvoor kiest. Je browser kan eigen functies zoals automatisch aanvullen of sessieherstel gebruiken.

Lettertypen en weergave

De pagina’s vragen lettertypen op bij Google Fonts. Bij het laden daarvan maakt je browser verbinding met Google. De gekozen kleurweergave wordt via de paginalink doorgegeven. Deze versie bevat geen door ORYONX toegevoegde analytische of advertentietrackers.

Voorbeelden en inhoud

De werkvoorbeelden zijn fictieve demonstraties. Ze zijn geen bewijs van uitgevoerde opdrachten of behaalde resultaten. De artikelen beschrijven onze kijk op het werk.

Vragen over deze website

Bel ORYONX als je een vraag hebt of een probleem tegenkomt. Deze website wordt gehost via GitHub Pages. GitHub registreert IP-adressen voor beveiligingsdoeleinden. Meer informatie staat in de privacyverklaring van GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.
